# Security Policy

## Reporting a vulnerability

Please do not publish a security-sensitive issue with exploit details in a public issue before the problem can be reviewed.

If you discover a vulnerability involving process termination, privilege handling, command-line exposure or local process inspection, contact the repository owner privately through the GitHub profile first.

## Scope notes

Localhost Radar reads local TCP listener and process metadata. Some process information may require elevated Windows permissions. The application is not intended to bypass operating-system access controls.
